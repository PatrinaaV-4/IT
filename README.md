# IT

🖥️ AR-приложение для IT Полигона

🌐 Обзор проекта

Это инновационное AR-приложение, которое выводит детализированные трехмерные модели оборудования IT Полигона прямо на ваше устройство при сканировании специального маркера. Простое взаимодействие с объектами создает интерактивный опыт, помогая глубже понять структуру и возможности оборудования.

💡 Особенности

🔍 Быстрое распознавание маркеров

🧩 Интерактивные элементы интерфейса

🚀 Реалистичные 3D-модели высокого качества

👾 Легкость интеграции с существующими системами мониторинга

🚀 Быстрый старт

Требования к системе:
Android-устройство версии 8.0+
Достаточное освещение рабочей зоны
Распечатанные маркеры (QR-коды)
